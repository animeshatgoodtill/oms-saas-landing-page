# SEO & Deployment Skill

## Deployment

### Platform: Vercel
- Auto-deploys from GitHub on push to `main`
- No `vercel.json` config file - uses framework defaults
- Production domain: `www.opscel.com`
- Application domain: `app.opscel.com` (separate repo)

### Build Process
```bash
npm run build    # Next.js production build
npm run start    # Serve locally (production mode)
```

### Environment Variables
- `GOOGLE_ANALYTICS_ID`: Set in Vercel dashboard (see `.env.example`)
- No other env vars required - this is a static marketing site

---

## SEO Configuration

### Metadata (src/app/layout.tsx)
Root layout defines:
- `title` and `description` from `siteDetails.ts`
- OpenGraph tags (title, description, URL, site name, type, locale)
- Twitter card tags (card type, title, description)
- Favicon configuration (ico, webp, apple icon)

### Sitemap (src/app/sitemap.ts)
- Auto-generated by Next.js at `/sitemap.xml`
- Includes all static routes and dynamic feature pages
- Update when adding new routes

### Robots (public/robots.txt)
- Static file at `/robots.txt`
- References sitemap URL

### Google Analytics
- Integrated via `@next/third-parties/google` in layout.tsx
- GA ID configured in `src/data/siteDetails.ts` → `googleAnalyticsId`
- Only loads when ID is present

## Adding New Pages (SEO Checklist)

When creating a new page:

1. **Route**: Create in `src/app/<path>/page.tsx`
2. **Metadata**: Export `metadata` object or use `generateMetadata()` for dynamic pages:
   ```tsx
   export const metadata = {
     title: 'Page Title | Opscel',
     description: 'Page description for search engines',
   };
   ```
3. **Sitemap**: Verify it appears in `sitemap.ts` output
4. **Navigation**: Add to `menuItems.ts` if it should be in the nav
5. **Footer**: Add to `footer.ts` if it should be in footer links
6. **Heading hierarchy**: Use h1 once per page, then h2/h3 in order
7. **Images**: Use Next.js `Image` component with `alt` text, `width`/`height`, and `sizes` prop

---

## Performance Considerations

- **Images**: Always use `.webp` format with Next.js `Image` component
- **Fonts**: Loaded via `next/font/google` (self-hosted after build, no CLS)
- **Animations**: Framer Motion only where needed; CSS for simple effects
- **Code splitting**: Automatic per-route via Next.js App Router
- **No external CSS**: All styles via Tailwind (tree-shaken) + CSS variables
