# Opscel Marketing Site

Marketing website for [Opscel](https://opscel.com) - AI-Native Operations Management for Fire Safety Contractors.

## Tech Stack

- **Next.js 14** with App Router
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **TypeScript**

## Development

```bash
npm install
npm run dev
```

## Deployment

Deployed via Vercel to `www.opscel.com`.
